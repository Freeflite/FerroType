FerroType 0.2.0 adds an optional lock on the saved history: a YubiKey or another FIDO2 security key.

## New: lock the saved history with a security key

- **Settings → Security key → Lock with a security key.** Your pins (and the whole history, if it's saved between runs) are encrypted so that after FerroType restarts, unlocking takes the key, its PIN and a touch. Someone who gets into your Windows account, or copies the file, can't read it without the key.
- **Backup keys.** Register more than one key; any of them unlocks. Lose every registered key and the locked entries can't be recovered.
- **Windows does the asking.** FerroType uses Windows' own security-key API, which shows its own PIN and touch prompts: FerroType never sees the PIN, needs no administrator rights or network, and uses none of the key's passkey slots.
- **How it's built:** AES-256-GCM with a random data key, stored once per registered key under a key derived (HKDF-SHA256) from that key's `hmac-secret` answer; DPAPI still wraps the file. See [SECURITY.md](https://github.com/Freeflite/FerroType/blob/main/SECURITY.md).
- Needs a key with FIDO2 `hmac-secret` (YubiKey 5 and Security Key series, and most others) and Windows 11 or a recent Windows 10. Without a key, nothing changes.

## New: install it, if you like

- **Settings → Installation → Install** copies FerroType into your own Programs folder and adds it to the Start menu and to Settings → Apps, for your Windows account only, with no administrator rights. **Update to this version** replaces an older installed copy, and **Uninstall** (here or in Settings → Apps) removes it again. Your settings and history stay either way.
- It's optional: FerroType still runs from wherever you put it.

## Also

- **One FerroType at a time.** Starting it while it's already running brings the running one to the front, so two copies can't fight over the hotkeys or save over each other's history.
- **A locked history file is never overwritten** by a FerroType that hasn't unlocked it.
- Screenshots in the README.
- The README is clearer about reproducible builds: the same toolchain gives the same exe, and the attestation shows where each release's exe came from.

## Download

- **`ferrotype.exe`**: the whole program in one file. No runtime to install; run it from anywhere, or install it from Settings.
- **`ferrotype-0.2.0-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11. Your settings and history from 0.1.0 carry over.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows "Windows protected your PC". Choose **More info → Run anyway**.

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotype.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI from the tagged commit. With the GitHub CLI: `gh attestation verify ferrotype.exe --repo Freeflite/FerroType`

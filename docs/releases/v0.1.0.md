The first release of FerroType, the clipboard typing utility: it types text into windows that
won't take a paste (remote sessions, VM consoles, installers, sign-in screens), one real
keystroke at a time.

## What's in it

- **Typing with real keys** on the target window's keyboard layout, with a random pause after
  each key, a countdown to click into the target, progress and a time estimate. It keeps typing
  when Windows reports a focus change (common over Remote Desktop), waits while FerroType itself
  has the focus or a modifier is held, and waits out a locked screen without doubling a
  character.
- **Start and stop hotkeys** (Ctrl+Alt+F9 to start with), set by typing or recording them.
  Combinations that would break other programs, or that Remote Desktop keeps, are refused.
- **History and pins** (History tab): text you copy and type, newest first, with pinned entries
  on top. Click a line to edit it, or press its play button to type it. Text only; passwords
  copied from password managers are skipped (a setting); limits on entries and size; strict
  (save pins only), saved or no history; saved data encrypted with DPAPI.
- **Settings**: hotkeys, history, skipping passwords, and light, dark or matching Windows.

## Download

- **`ferrotype.exe`**: the whole program in one file. No installer, no runtime to install; run it
  from anywhere.
- **`ferrotype-0.1.0-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows
"Windows protected your PC". Choose **More info → Run anyway**. If you'd rather check what
you're running first, see below, or build it yourself from the source with
`pwsh scripts/build-release.ps1`: the build is reproducible.

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotype.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI
  from the tagged commit. With the GitHub CLI:
  `gh attestation verify ferrotype.exe --repo Freeflite/FerroType`

See the [README](https://github.com/Freeflite/FerroType#readme) for how it works and
[SECURITY.md](https://github.com/Freeflite/FerroType/blob/main/SECURITY.md) for how it's
hardened and how to report a problem.
